# src/shared/api — сеть и ошибки

- `request(url, { schema, ... })` — единственный путь в сеть. Схема обязательна: ответ не
  по контракту — `AppError("unknown")`, а не тихий `undefined` в UI.
- Выше этой папки никто не читает `Response`, статусы и тексты ошибок — только
  `AppError.kind` и `details` (`status`, `fieldErrors`, `retryAfter`).
- Формат тела ошибки бэкенда описан один раз — `ErrorBodySchema` в `request.ts`. Меняй его
  под контракт бэкенда, а не разбирай тело ошибки в фичах.
- GraphQL отвечает 200 и на ошибки: проверяй весь массив `errors` и определяй `kind` по
  `extensions.code`. По тексту сообщения — только если кодов нет, в одной функции, с
  комментарием и тестом на каждую строку.
- Повторы (`shouldRetry`) — только для `network` и 5xx. 4xx от повтора не исправятся.
- Запросы конкретных сущностей сюда не кладутся: фабрика `queryOptions` и маппинг DTO —
  в `entities/<x>/api` (или в `pages/<page>/api`, если сущность нужна одной странице).
- Тесты — MSW: каждый тест объявляет свою сеть через `server.use()`, незамоканный запрос
  валит тест. Новый вид ответа — новый тест в `request.test.ts`.
